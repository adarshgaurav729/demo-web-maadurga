# Maa Durga Enterprises & Home Appliances - Official Website

A modern, fast, and high-converting static eCommerce website for **Maa Durga Enterprises & Home Appliances**, located in Bara Chakia, Sahebganj, Bihar.

---

## 🌟 Key Highlights & Features

- **Tech Stack:** 100% Pure HTML5, CSS3, and Vanilla JavaScript.
- **Zero Dependencies:** No React, no Node.js, no npm, no build steps required. Simply open `index.html` in any web browser!
- **Color Theme:** Trustworthy Blue & Crisp White corporate retail theme (inspired by Samsung & Reliance Digital).
- **Core Product Showcases:**
  - 📱 **Smartphones:** Samsung, Vivo, Realme, Xiaomi, OnePlus
  - 📺 **Smart TVs:** 32" to 55" 4K UHD Smart Android & WebOS TVs
  - 🚪 **Triveni Almirah:** Official authorized stockist showcase with heavy gauge steel almirahs & wardrobes
  - 🧊 **Home Appliances:** Refrigerators, washing machines, desert air coolers, mixer grinders
  - 🎧 **Accessories:** Fast chargers, cables, earbuds, and power banks
- **Customer Conversion Engine:**
  - 1-Click WhatsApp Enquiry with auto-populated product names & prices
  - Click-to-Call showroom direct button (`082102 11632`)
  - Embedded Google Maps showroom locator (Plus Code: `C23W+HM, Sahebganj, Bihar`)
  - Instant in-store 0% EMI financing guidance (Bajaj Finserv & TVS Credit)
  - Interactive Quick View Product Modal
  - Live search and category filters on the Shop page
  - Interactive WhatsApp inquiry builder on the Contact page

## 🚀 How to Run Locally

Simply double-click `index.html` or open it with any web browser (Google Chrome, Edge, Safari, Firefox).

Or run using Node.js:
```bash
node server.js
```

---

## 🌐 How to Deploy to GitHub Pages

1. Push this folder to a GitHub repository (`demo-web-maadurga`).
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. Your website is live worldwide at `https://<your-username>.github.io/<repo-name>/`!
